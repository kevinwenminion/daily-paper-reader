## 摘要
直接从磁力测量中提取内在的磁性哈密顿量是充满挑战的，原因在于参数空间的高维性以及系综平均引起的简并性。在此，我们引入一组深度卷积神经网络（CNNs），直接从一阶反转曲线（FORCs）中编码的磁指纹中提取完整的唯象微磁哈密顿量。我们通过闭环验证来验证这一方法，为模拟和实验的FORCs重新创建输入磁力测量。为了减少误报，我们部署了一个“Alice-Bob”并行网络，该网络仅基于FORC中的信息量化预测不确定性，而无需任何额外的真值知识。这一框架提供了一种鲁棒的、机器学习辅助的方法，以揭示复杂磁系统中潜在的自旋行为。

## Abstract
Extracting intrinsic magnetic Hamiltonians directly from magnetometry is challenging due to the high dimensionality of the parameter space and the degeneracy induced by ensemble averaging. Here, we introduce a collection of deep convolutional neural networks (CNNs) to extract the full phenomenological micromagnetic Hamiltonian directly from the magnetic fingerprints encoded within First-Order Reversal Curves (FORCs). We validate this approach via closed-loop verification, re-creating the input magnetometry for both simulated and experimental FORCs. To mitigate false positives, we deploy an `Alice--Bob' parallel network that quantifies prediction uncertainty based on solely the information in FORCs without any additional ground-truth knowledge. This framework provides a robust, machine-learning-assisted approach to unravel the underlying spin behaviors in complex magnetic systems

## 1. 论文的核心问题与整体含义（研究动机和背景）

- 磁学研究的核心挑战之一：如何将宏观磁行为与微观自旋相互作用定量联系起来。经典微磁哈密顿量（包含海森堡交换作用、磁晶各向异性、磁偶极相互作用、DMI 等）能有效描述磁化动力学、自旋波、磁开关及复杂自旋织构（气泡、涡旋、斯格明子等），但其预测能力依赖于完整且准确地知道所有哈密顿参数。
- 实验上直接提取这些参数极为困难：传统方法通常需要多种资源密集型测量手段并结合迭代理论建模，尤其 DMI 等相互作用难以分离，需要专门设备和复杂测量。
- 本文瞄准的逆问题：从易于获取的宏观磁测数据（空间和热平均后的磁化强度测量）直接反推完整微磁哈密顿量。该逆问题难点在于：

## 6. 论文的主要结论与发现

- 磁测数据的空间平均并未完全抹掉微观自旋物理信息：FORCs 中的小磁滞回线包含丰富的结构特征（源于畴壁钉扎和各能量项竞争），足以提取完整微磁哈密顿量。
- 独立训练的 CNN 可以分别准确预测交换刚度 Aex、单轴各向异性 Ku、钉扎中心密度 Npin 和 DMI D，且误差在可接受范围内。
- 闭环验证表明，用预测参数重建的 FORCs 能重现关键磁特征（矫顽力分布、反转陡度、小回线形状），尤其是在 FORCs 具有丰富细节时；特征平淡（几乎所有 FORCs 与主环重合）的情况下预测误差较大，说明物理信息主要隐藏在偏离主环的小回线中。
- Alice-Bob 网络能仅基于 FORC 内部特征有效识别高风险预测（高误差样本），并与真实误差高度相关，为无真值场景提供可靠性指标。
- 在实验 Co/Pd 多层膜上，预测参数重建的 FORCs 能捕获主要宏观磁特征（矫顽力、磁化率、回线方形度），但整体匹配度低于模拟闭环最佳情况，提示需扩展更真实的哈密顿量模型。

## 7. 优点

- **创新性地将逆问题转化为图像识别任务**：FORC 重排为 2D 图像并利用 CNN 提取指纹，避免了高维参数空间的手工特征设计。
- **独立参数预测架构**：每个哈密顿参数由独立 CNN 预测，迫使网络独立学习每个相互作用在 FORCs 中的特征，增强了可解释性和鲁棒性，也证明各参数指纹独立存在。
- **闭环验证**：不止用标量误差评估，还通过正向模拟重建磁测曲线，直接反映物理保真度，是更可靠的验证方式。
- **Alice-Bob 不确定性量化**：无需真值即可预测误差分位数，为实际应用中的可靠性判断提供重要工具。
- **数据生成策略精细**：采用零温模拟避免热噪声伪影；自适应扫描速率平衡精度与速度；引入结构无序（钉扎点、各向异性涨落）模拟真实材料特性，使训练数据更具代表性。
- **结合实验验证**：从模拟到实验的迁移可行性得到验证，增加了实际应用说服力。

## 8. 不足与局限

- **模型哈密顿量简化**：仅考虑交换、单轴各向异性、DMI 和钉扎，未包含更高阶项（如界面 DMI 的各向异性、多体相互作用、热效应等），限制了在真实复杂材料中的精度。
- **实验验证有限**：仅一个样品、一组生长条件，且 Ms 需作为已知/扫描输入处理，真实应用中 Ms 也可能有不确定性；重建效果与实验输入的符合度有限。
- **数据分布偏差风险**：训练数据由特定采样分布（均匀 Ms、三角分布 Ku、正态分布交换长度等）生成，可能无法覆盖真实材料参数的所有组合，导致外推能力有限。
- **无序模型简化**：钉扎点和区域划分是人工设定，与真实微观结构（晶界、缺陷形态、层间粗糙度等）存在差异，可能造成系统误差。

- **无消融实验**：未分析 Ms 注入、网络深度、Dropout、数据集大小等因素对性能的影响，也未与其他机器学习方法对比。
